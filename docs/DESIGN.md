# Zeta Lab 首章设计

Zeta Lab 是 Godot 原生桌面游戏。Lean 4 工坊从自然数等式、递归累加、归纳证明和定理复用起步。玩家写真实 Lean 定义和证明，提示分层出现，图解按需打开。后续知识树从级数、积分、复变和数论通向准黎曼猜想预印本的精读与复推。远期节点当前展示课程方向。

编辑器可折叠，可新建 Lean 草稿，内置关卡按前置解锁。通过验收的定理保存到知识架，后续关卡能够调用。机械臂用教学生成的动作呈现检查成功后的试算、归档或改写。失败时保留本次内容并显示 Lean 诊断。

曾考虑指令积木和图解优先的证明台。最终采用直接编写 Lean 4 的常驻黄铜工坊，知识树和图解在按需打开的浮层里显示。
